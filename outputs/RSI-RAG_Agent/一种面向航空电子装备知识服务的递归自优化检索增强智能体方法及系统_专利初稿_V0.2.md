# 说 明 书 摘 要

本发明公开了一种面向航空电子装备知识服务的递归自优化检索增强智能体方法及系统，包括如下步骤：S1、接收航空电子装备知识任务，解析任务类型、装备对象及所需证据类型，基于检索增强智能体生成检索任务图并调用领域知识库完成多阶段检索、证据聚合与充分性验证，形成完整检索执行轨迹；S2、对通过结果验证的检索执行轨迹进行经验提炼，生成包含任务条件、检索动作、执行结果、策略效果诊断、验证状态及来源版本信息的检索经验单元，并通过正负经验对比、多经验聚合及冲突消解生成或更新检索编排策略；S3、在后续知识任务中根据当前任务特征匹配已验证的检索编排策略，将所述策略作为策略覆盖信息作用于智能体规划过程，对任务分解、查询扩展、知识源路由、工具调用、上下文扩展或停止条件中的至少一项进行调整，并依据新任务的验证结果持续更新策略状态。与现有技术相比，本发明在任务执行层形成可验证的完整检索轨迹，在经验层将轨迹转化为可复用且可区分正负结果的检索经验，在策略层通过门控、版本管理和可回滚更新实现知识获取策略的递归自优化，从而降低相似航空电子知识任务中的重复无效检索和错误经验累积，提高复杂知识服务的证据覆盖稳定性与长期适应能力。

# 说 明 书

## 一种面向航空电子装备知识服务的递归自优化检索增强智能体方法及系统

## 技术领域

本发明涉及航空电子装备知识服务与人工智能技术领域，具体涉及一种面向航空电子装备领域知识库的递归自优化检索增强智能体方法及系统。

## 背景技术

航空电子装备包含电源板、电路板、控制模块、通信模块、接口模块等多种电子设备，其设计、测试和维修过程依赖大量技术资料，包括工作原理文档、维修手册、故障隔离资料、测试规程、器件说明、技术通告及历史维修案例等。上述资料来源多、版本多、专业术语密集，并且不同型号和功能模块之间存在较强的适用范围约束。对于研发、测试和维修人员而言，如何从多源资料中快速获得能够直接支撑当前任务的知识证据，是提高航空电子装备知识利用效率的重要基础。

近年来，检索增强生成技术通过在大语言模型生成之前从外部知识库检索相关文档，可使模型利用私有领域资料回答专业问题。进一步地，基于智能体的检索增强方法能够对复杂问题进行任务分解，根据中间结果进行多轮检索，并调用关键词检索、向量检索、限定文档检索及上下文扩展等不同工具，相比一次性检索方式能够提高复杂知识任务的处理能力。

然而，在航空电子装备知识服务场景中，现有检索增强方法仍存在两个关键瓶颈：

（1）跨任务的有效检索经验难以稳定沉淀和复用。现有系统通常针对每一次用户请求重新执行问题分解、查询改写、知识源选择和工具调用；即使保存历史对话或检索日志，这些历史信息也主要作为文本上下文使用，缺少将“某类任务在何种条件下采用何种检索路径能够获得充分证据”提炼为结构化检索策略的机制。因此，在相似航空电子知识任务反复出现时，系统仍可能重复执行无效查询、重复访问不合适的知识源，或在不同任务间产生不稳定的检索路径。

（2）长期自优化过程中存在错误经验和过时经验污染风险。航空电子资料具有严格的型号、模块和版本适用性，同一故障现象在不同设备或不同版本手册下可能对应不同测试流程。若系统仅依据单次成功、用户简单反馈或未经充分验证的历史记录直接修改后续检索行为，则偶然命中的结果、错误答案或旧版本文档可能被长期固化，并在后续多个任务中持续传播。现有技术缺少针对检索经验的独立验证、正负经验对比、适用范围约束、策略冲突消解以及版本回滚机制。

综上所述，现有技术尚未能提供一种有效方案，使航空电子装备领域的检索增强智能体能够把经过验证的检索执行过程转化为可复用的检索策略，并在后续任务中持续改进知识获取路径，同时抑制错误经验和过时策略的长期累积。因此，亟需研究一种面向航空电子装备知识服务的、具有受验证约束的递归自优化能力的检索增强智能体方法及系统。

## 发明内容

本发明需要解决的实际问题是：在航空电子装备知识资料来源多、版本复杂、任务类型多样的条件下，使检索增强智能体能够利用已经验证的历史检索过程持续改进后续知识获取策略，减少相似任务中的重复无效检索，并避免错误或过时经验在长期策略记忆中累积传播。

为了解决上述问题，本发明公开了一种面向航空电子装备知识服务的递归自优化检索增强智能体方法，具体方法如下：

S1、知识任务执行与检索轨迹形成：接收航空电子装备知识任务，解析所述知识任务的任务类型、装备对象、任务意图及所需证据类型，生成检索任务图；根据所述检索任务图调用航空电子装备领域知识库中的检索工具进行多阶段检索，将检索结果写入证据池，并对证据充分性及任务链路进行验证；若证据不足，则根据缺失证据继续调整检索任务图并执行补充检索；当证据满足预设任务结束条件后输出知识服务结果，并形成包含任务规划、检索动作、证据变化及验证结果的检索执行轨迹；

S2、检索经验提炼与策略递归更新：对步骤S1形成的检索执行轨迹进行结果验证；对于满足经验提炼条件的检索执行轨迹，提炼生成检索经验单元；在历史检索经验中检索与当前任务条件相近的正向经验和负向经验，对其检索动作及对应结果进行对比，并对多条已验证经验进行聚合；当新经验与已有策略冲突时，根据装备对象、任务意图、知识需求类型及知识库版本进行冲突消解，生成或更新具有适用范围、验证状态及版本信息的检索编排策略；

S3、策略增强的后续知识服务：接收后续航空电子装备知识任务，根据当前任务特征匹配已验证的检索编排策略；将匹配得到的检索编排策略作为策略覆盖信息作用于检索增强智能体的规划过程，对任务分解、查询扩展、知识源路由、检索工具序列、上下文扩展方式或停止条件中的至少一项进行调整；完成后续知识任务后，再根据该任务的验证结果执行步骤S2，使检索编排策略随已验证任务经验持续递归更新。

进一步地，步骤S1中所述航空电子装备领域知识库包括技术手册、工作原理资料、维修手册、故障隔离资料、历史故障案例、测试规程、器件说明及技术通告中的至少一种。对文档进行解析和分块后，可建立关键词索引和向量索引，并为文档片段关联装备型号、功能模块、文档类型、版本、章节或页码等元数据。本发明不要求构建知识图谱。

进一步地，步骤S1中所述检索任务图由一个或多个检索子任务构成。对于无依赖关系的子任务可以并行执行，对于存在依赖关系的子任务，后续子任务可引用前序子任务已经验证的中间结果。所述检索工具包括关键词检索、向量检索、混合检索、重排序、限定文档检索、指定页上下文检索及父块或相邻块扩展中的至少一种。

进一步地，步骤S1中所述证据充分性验证用于判断当前证据池是否覆盖当前知识任务要求的证据类型。对于故障原因分析类任务，所需证据可以包括工作原理、故障现象、历史案例及测试方法；对于测试规程类任务，所需证据可以包括测试步骤、测试点、正常范围及判据；当证据未覆盖所需信息时，系统输出缺失证据类型及补充检索要求，并重新进入检索任务图执行过程。

进一步地，步骤S2中所述检索经验单元包括任务条件信息、检索动作信息、执行结果信息、策略效果诊断信息、验证状态信息和来源版本信息。其中，任务条件信息用于描述任务类型、装备类型、功能模块、用户意图、任务复杂度和所需证据类型；检索动作信息用于描述任务分解方式、查询扩展方式、知识源路由、工具调用序列、上下文扩展方式和停止条件；执行结果信息用于描述证据覆盖情况、链路验证结果、知识服务结果证据支持情况及检索调用情况；策略效果诊断信息用于记录已观察到的不足及候选改进方向；验证状态信息用于区分候选经验、已验证正向经验、已验证负向经验、重复支持经验和失效经验；来源版本信息用于记录检索轨迹标识、知识库版本、文档版本以及相关组件版本。

进一步地，步骤S2中设置结果门控机制。对于未形成可靠证据验证结论、知识服务结果未得到证据支持、检索过程中存在无法与策略效果区分的基础设施异常、或轨迹缺失关键版本信息的任务，不将其直接用于生成长期检索策略，而仅保留为隔离轨迹或审计记录。通过结果门控的成功轨迹可生成已验证正向经验；通过结果门控的失败轨迹可生成已验证负向经验。

进一步地，步骤S2中所述正负经验对比用于在任务条件相近的经验之间比较检索动作差异。例如，若同类任务的失败经验只使用通用语义检索，而成功经验增加了限定手册检索、专业术语扩展及测试规程检索，则将所述动作差异作为候选策略修改项。通过多条已验证经验的重复支持，形成具有适用范围、策略修改内容、支持经验、反向证据及版本信息的候选检索编排策略。

进一步地，步骤S2中还设置策略门控机制。只有候选检索编排策略满足预设的重复支持、正负对比支持、来源可靠性或冲突解决条件后，才将其写入可影响后续任务的长期策略记忆。对于未通过策略门控的候选策略，仅作为经验保留，不直接改变后续智能体行为。

进一步地，当新经验与已有检索编排策略冲突时，根据设备型号、功能模块、任务意图、知识需求类型、知识库版本或文档版本分析冲突来源。当冲突由适用条件不同造成时，对策略适用范围进行收缩或策略分裂；当已有策略在新版本知识环境中持续出现负向验证时，对其进行可信等级降低、失效标记、策略替换或回滚至历史稳定版本。

进一步地，步骤S3中所述策略覆盖信息不直接替换基础规划器。系统保留基础规划器，根据当前任务与历史检索编排策略的匹配结果，将策略覆盖信息作为附加规划条件输入基础规划器。策略覆盖信息可以规定优先知识源、专业术语扩展方向、优选检索工具、上下文扩展方式及证据停止条件，由基础规划器结合当前问题生成最终检索任务图。

本发明通过上述步骤，构建了一个从当前知识任务执行、检索轨迹验证、检索经验提炼、长期策略形成到后续任务策略增强的完整递归自优化流程。与现有技术相比，本发明所述方法通过三个层面的有机结合形成完整解决方案。首先，在任务执行层面，通过检索任务图、证据池及独立证据验证机制获得具有可追踪性的完整检索执行轨迹，使后续自优化基于已验证的真实执行过程而非仅基于问答文本；其次，在经验学习层面，通过检索经验单元、正负经验对比、多经验聚合及冲突消解机制，将一次性检索过程转化为具有明确适用范围的可复用检索策略，降低单次偶然结果造成的过度泛化；最后，在策略决策层面，通过策略覆盖信息、双门控、版本管理及回滚机制，使历史经验能够直接改变后续检索任务图，同时限制错误或过时策略的传播，从而实现面向航空电子装备知识服务的受验证递归自优化。

## 具体实施方式

下面结合附图对本发明作进一步的详细说明。

如图1所示，本发明公开了一种面向航空电子装备知识服务的递归自优化检索增强智能体方法，包括如下步骤：

S1、知识任务执行与检索轨迹形成：接收航空电子装备知识任务，形成任务特征并生成检索任务图；执行多阶段检索、证据聚合和证据充分性验证，并记录完整检索执行轨迹；

S2、检索经验提炼与策略递归更新：对通过结果门控的检索执行轨迹进行经验提炼，形成检索经验单元；基于相似任务的正向和负向经验进行对比、聚合和冲突消解，生成或更新检索编排策略；

S3、策略增强的后续知识服务：针对后续知识任务匹配已验证的检索编排策略，将其作为策略覆盖信息作用于基础规划器以生成新的检索任务图，并依据新任务验证结果继续更新所述检索编排策略。

在具体实施例中，以航空电子装备中的多通道DC/DC电源模块知识服务为例。知识库中预先存入该类装备的工作原理资料、维修手册、测试规程、历史故障案例、器件说明和技术通告。对各类文档进行解析、分块和索引，并为文档片段记录文档类型、装备型号、功能模块、文档版本、章节和页码等元数据。检索层同时提供关键词检索与向量检索，并可进一步进行混合排序或重排序。

当用户提出第一类任务：“某多通道DC/DC电源模块的一路输出电压持续偏低，可能涉及哪些环节，应如何查证？”时，系统首先对问题进行任务解析，得到如下任务特征：任务类型为故障原因分析，装备对象为航空电子电源模块，任务意图为原因分析与测试验证，任务复杂度为多跳任务，所需证据至少包括工作原理、故障案例以及测试步骤或判据。

如图2所示，系统首先进入当前任务内循环。基础规划器将问题分解为若干检索子任务，例如：检索输出电压偏低的历史故障案例；检索稳压反馈、采样或控制环路的工作原理；检索对应模块的测试步骤、测试点及正常范围。若子任务之间存在依赖关系，则后续子任务可使用前序已经验证的中间结果生成更具体的查询。

在第一次执行中，假设系统首先通过通用混合检索获得若干“输出电压异常”历史案例。证据验证模块发现当前证据能够说明若干可能原因，但缺少反馈调节原理及测试规程，尚不足以回答“应如何查证”。因此，证据验证模块输出缺失证据类型，并将“工作原理”和“测试规程”作为补充检索要求返回基础规划器。

基础规划器据此新增检索任务：一是使用“反馈、采样、稳压、误差调节”等专业术语对工作原理资料进行检索；二是限定维修手册或测试规程文档进行检索；三是在命中特定测试程序后读取对应页或相邻页上下文，以获得完整的测试步骤和判据。各次检索结果经去重、排序和上下文扩展后进入证据池。

当证据池已经覆盖工作原理、历史案例和测试步骤，且最终回答中的关键结论均能够由所述证据支持时，当前任务结束。系统保存完整检索执行轨迹。所述轨迹包括任务特征、检索任务图、每次查询内容、知识源选择、工具调用、召回文档、证据池变化、证据充分性判断、补充检索原因、最终回答验证结果以及当前知识库和文档版本。

如图3所示，随后进入跨任务递归自优化外循环。结果门控模块首先判断该轨迹是否具备经验提炼条件。在本实施例中，该任务具有明确的证据充分性判断和最终回答验证结果，轨迹字段完整，因此通过结果门控。

系统基于该轨迹生成一条正向检索经验单元。该经验单元中的任务条件包括“电源模块输出异常、原因分析、需要测试证据”；检索动作包括“先进行通用检索、根据证据缺口补充反馈控制原理检索、限定测试规程检索及页级上下文扩展”；执行结果包括“机理、案例和测试三类证据均获得覆盖”；来源版本包括当前知识库版本及手册版本。

若历史中还存在一条相似的负向经验，例如另一任务仅通过通用向量检索获得故障案例并直接生成回答，但由于缺少测试步骤而未通过证据验证，则系统将该负向经验与本次正向经验进行对比。通过比较可发现，二者的主要检索动作差异包括：是否增加反馈控制相关专业术语扩展、是否将测试规程作为独立知识源、是否在命中文档后进行页级上下文扩展。

如图4所示，系统将上述差异与其他相似任务的已验证经验进行聚合。当多个任务重复表明“输出异常原因分析且需要测试方法”类问题需要同时覆盖工作原理、历史案例和测试规程时，形成候选检索编排策略。该候选策略可表示为：适用于航空电子电源模块输出异常原因分析类任务；优先把问题分解为工作原理、故障案例和测试规程三个知识子任务；在查询扩展中增加反馈、采样、稳压等专业词；在测试规程命中后优先读取对应页及相邻页；当机理、案例和测试证据均获得支持后允许结束检索。

上述候选策略不能在生成后立即影响所有任务。策略门控模块进一步检查该候选策略是否得到多条独立已验证经验支持、是否存在尚未解决的反向证据以及适用范围是否明确。当满足门控条件后，将所述候选策略晋级为长期检索编排策略，并记录支持经验标识、反向经验标识、知识库版本及策略版本。

当后续用户提出：“另一输出通道在带载时电压下降，应该从哪些资料确认原因？”时，如图5所示，系统先生成当前任务特征，并从长期策略记忆中检索到前述检索编排策略。系统将该策略转化为策略覆盖信息，并与当前问题共同输入基础规划器。因此，基础规划器无需完全从零开始探索，而是优先生成包含工作原理、故障案例和测试规程的检索任务图，同时结合“带载时电压下降”这一新条件进一步增加负载特性、过流保护或供电能力等查询方向。

在本实施例中，策略覆盖信息仅提供检索偏好和证据要求，不直接输出最终答案。因此，当后续问题与历史任务存在差异时，基础规划器仍可根据当前问题修改检索子任务，避免将历史策略机械套用到新的装备或新的故障现象。

对于简单参数查询，例如用户询问“某模块额定输入电压范围是多少”，任务解析结果表明该任务仅需要权威技术手册中的单一参数证据，与上述“故障原因分析”策略的适用范围不匹配。因此，系统不加载复杂策略覆盖信息，仅采用限定手册检索或基础RAG完成任务，从而避免不必要的多轮检索。

进一步地，考虑航空电子装备技术资料版本更新的情况。假设某检索编排策略是在旧版维修手册条件下形成，而知识库后续加入新版维修手册，新版手册已经调整故障隔离步骤。若系统继续使用旧策略，在多个新任务中可能出现“旧章节相关但测试程序与当前版本不一致”的负向验证结果。此时，系统利用来源版本信息识别冲突来源，并将旧策略的适用范围限定到旧版资料，同时形成面向新版资料的新候选策略；若旧策略在当前知识库版本下持续失败，则降低其优先级、标记为失效或回滚到历史稳定策略，并允许基础规划器重新进行无策略探索。

通过上述实施方式，本发明能够在不重新训练基础大语言模型参数的情况下，使航空电子装备知识服务智能体的检索规划能力随已验证任务经验逐步积累。实际部署时，可通过以下指标验证本发明的技术效果：相似任务的平均检索调用次数、重复无效查询比例、所需证据类型覆盖率、最终回答证据支持率、补充检索轮数、过时策略引起的负向验证次数以及策略回滚次数等。上述指标仅用于实施效果评价，不构成对本发明保护范围的限定。

以上表述显示了本发明的实施方式和技术效果，以上所述实例仅为本公开的优选实例，并不限制于本公开。对于本领域技术人员而言，在不脱离本发明核心构思的情况下，对检索工具类型、基础模型类型、经验存储方式、策略匹配方式及门控实现方式作出的等同替换或改进，均应落入本发明保护范围内。
