# Step 10-1：专利点分析与发明构思选定

## 1. 案件边界

- **技术主题**：面向航空电子装备垂直领域知识服务的递归自优化检索增强智能体（RSI-RAG Agent）。
- **专利类型**：发明（默认）。
- **应用对象**：航空电子装备知识库及其知识检索、问答、故障机理解释、测试规程查询、维修案例查询等知识服务。
- **知识形态**：维修手册、原理/设计资料、故障案例、测试规程、器件资料、技术通告等文本或半结构化资料；本案**不以知识图谱为必要技术手段**。
- **技术联系人**：待填写。

## 2. 已有技术基础

现有 Agentic RAG 原型已经具备任务路由、检索任务规划、混合检索、查询重写、证据池、证据充分性评分、链路验证、答案验证以及可追踪运行状态，可直接承担本案的“当前任务内循环”。

本案新增的核心不是再做一套普通 RAG，而是在当前任务完成后，把经过验证的检索执行轨迹转化为可复用的检索经验，并进一步形成能够影响未来智能体规划的检索编排策略，从而构成跨任务的递归自优化外循环。

## 3. 候选专利点

### 候选点 A：基于已验证检索轨迹的检索经验单元

**技术背景**：普通 RAG 或 Agentic RAG 通常记录日志、对话或当前任务反馈，但日志本身并不能直接作为后续任务的稳定策略依据。

**创新构思**：记录一次知识任务中的任务条件、任务分解、查询重写、知识源选择、工具调用序列、上下文扩展、证据充分性、链路验证、最终结果及文档版本，并在独立验证后提炼为检索经验单元 REU（Retrieval Experience Unit）。REU 至少区分任务条件、检索动作、执行结果、策略效果诊断、验证状态和来源版本。

**可实施性**：现有 Agentic RAG 的运行状态、step results、evidence pool、grade result、chain verification 已可提供大部分原始轨迹。

### 候选点 B：正负经验对比、聚合及冲突消解形成检索编排策略

**技术背景**：单条成功或失败记录容易受偶然因素影响，直接写入长期记忆可能造成错误经验传播。

**创新构思**：对适用条件相近的正向和负向 REU 进行对比，识别导致证据覆盖差异的检索动作；对多条已验证经验进行聚合，形成带有适用范围、可信度、支持经验、反例和版本信息的检索编排策略；新经验与旧策略冲突时，执行适用范围收缩、可信度调整、策略分裂、替换或失效处理。

**可实施性**：可由 LLM 负责语义归纳，由规则门控负责状态晋级、版本管理和回滚，不要求重新训练基础大模型。

### 候选点 C：RSI 策略覆盖层驱动 Agent 检索任务图演化

**技术背景**：普通 Agent 每次针对当前问题重新规划；即便存在历史 memory，也常仅作为附加上下文，而不是明确改变检索编排过程。

**创新构思**：保留基础 Planner，不直接改写基础提示词或模型参数；针对当前任务生成任务签名，从策略记忆中匹配已验证策略，以 Policy Overlay 的形式修改后续检索任务图中的至少一项：任务分解、查询扩展、知识源路由、工具序列、上下文扩展方式和停止条件。

**可实施性**：与现有 retrieval task graph、hybrid_search、search_by_file、page_context、expand_context 等工具层天然兼容。

### 候选点 D：双门控、版本日志与可回滚的受验证递归自优化

**技术背景**：长期自优化系统存在错误经验污染、旧版文档策略继续生效、策略越改越差等风险。

**创新构思**：设置 Outcome Gate 和 Policy Gate。只有具有可靠验证结果的任务轨迹才能晋级为 REU；只有获得重复支持或对比支持的经验才可晋级为可影响未来任务的策略。策略更新采用版本化日志，并保存更新原因、支持经验、知识库版本和回滚点。

**可实施性**：全部属于系统层状态管理，不依赖模型权重训练。

### 候选点 E：航空电子装备知识需求约束

**技术背景**：航空电子知识任务往往要求同时覆盖工作原理、故障现象、测试步骤、判据、维修措施、版本适用性等不同证据类型。

**创新构思**：在任务签名与证据充分性判断中引入装备类型、模块对象、任务意图、知识需求类型及文档版本等领域约束，使停止条件从“检索到若干相似文本”转变为“所需证据类型达到覆盖条件”。

**可实施性**：采用元数据和文本索引即可实现，无需知识图谱。

## 4. 融合后的总发明构思

将 A、B、C、D 融合为一条必要技术主线，E 作为航空电子领域中的具体约束和实施方式：

> 在航空电子装备知识服务过程中，由智能体完成当前任务的规划、检索、证据验证及回答；任务结束后记录完整检索执行轨迹，通过独立验证提炼检索经验单元；对多个已验证经验执行正负经验对比、聚合和冲突消解，生成具有适用范围与可信度的检索编排策略；在后续相似任务中，将匹配策略作为策略覆盖层作用于智能体检索任务图，从而使任务分解、查询构造、知识源路由、工具调用、上下文扩展或停止条件随已验证经验持续演化；同时利用双门控、来源版本和策略日志限制错误经验进入长期策略记忆。

该构思形成两个时间尺度上的闭环：

- **任务内循环**：规划 → 检索 → 证据评价 → 补查/重规划 → 生成与验证；
- **跨任务外循环**：轨迹 → 验证 → REU → 策略聚合/冲突消解 → Policy Overlay → 未来任务。

## 5. 选定工作标题

**一种面向航空电子装备知识服务的递归自优化检索增强智能体方法及系统**

英文概念名：**Recursive Self-Improving Retrieval-Augmented Generation Agent（RSI-RAG Agent）**

## 6. 本案暂不作为必要技术特征的内容

- 不把知识图谱作为必要技术手段；
- 不把某一种具体 embedding、reranker 或大语言模型型号作为必要技术特征；
- 不把在线微调或基础模型参数更新作为 RSI 的必要方式；
- 不把具体故障诊断小模型作为本案必要模块；
- 不把固定阈值、固定检索轮数和固定文档 Top-k 写死；
- 不把“Curriculum Agent / Actor Agent / Verifier Agent”三个角色名称原样搬用为保护核心，而是保护航空电子知识检索中的轨迹验证、经验提炼、策略演化和智能体规划作用关系。
