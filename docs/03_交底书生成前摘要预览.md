# Step 10-3：交底书生成前摘要预览（已按用户要求直接继续成文）

## 1. 选定名称

**一种面向航空电子装备知识服务的递归自优化检索增强智能体方法及系统**

概念简称：**RSI-RAG Agent（Recursive Self-Improving Retrieval-Augmented Generation Agent）**

**专利类型：发明（默认）**

## 2. 门禁与最接近现有技术

**门禁状态：带疑点过。**

最接近现有技术 D1：**CN119226439B《检索增强生成模型的控制方法、装置、设备及可读介质》**。该文献已公开基于历史交互和用户反馈调整 RAG 的关键词生成、文档特征提取及生成策略，因此“RAG 根据反馈自我优化”本身不作为本案核心区别。

组合风险 D2：**CN121329086A《一种基于多智能体与检索增强生成的智能管理调度系统及方法》**，已公开多智能体、RAG、执行反馈与持续学习闭环。

非专利近邻 **RSIAgent（arXiv:2609.15364）** 已公开 Agent 执行—独立验证—经验沉淀—未来复用的 training-free RSI 思路。

本案区别特征保持统一为：

- **F1**：从经过独立验证的完整检索执行轨迹形成 REU，区分任务条件、检索动作、结果、策略诊断、验证状态和来源版本。
- **F2**：对正负 REU 做对比式提炼，对多条经验聚合和冲突消解，形成带适用范围、可信度、支持经验、反例和版本信息的检索编排策略。
- **F3**：以 Policy Overlay 作用于基础 Planner，修改后续检索任务图中的任务分解、查询扩展、知识源路由、工具序列、上下文扩展或停止条件。
- **F4**：设置 Outcome Gate 与 Policy Gate，并采用版本日志、降权/失效和回滚机制限制错误经验污染。

## 3. 所要解决的技术问题

1. 如何使航空电子装备知识系统在多源文档、专业术语和复杂多跳问题环境下，能够利用已经验证的历史执行结果减少相似任务中的重复无效检索，并提高所需证据的覆盖稳定性。
2. 如何区分可复用的历史经验与偶发、错误或过时结果，避免错误经验在后续知识任务中持续传播。
3. 如何在不要求频繁更新基础大模型参数的条件下，使智能体的知识获取过程能够随任务积累和知识库版本变化持续适配，同时保持更新过程可追踪、可限制和可恢复。

## 4. 核心技术主线

当前任务首先进入 Agentic RAG 内循环，由智能体完成任务签名、策略匹配、检索任务图规划、混合检索、证据池累积、证据充分性判断、必要时补查以及答案/证据链验证。

任务完成后进入 RSI 外循环：保存检索执行轨迹，经结果门控后提炼 REU；检索相似历史 REU，执行正负经验对比、多经验聚合与策略冲突消解；通过策略门控后，将结果晋级为检索编排策略并写入版本化策略记忆。后续相似任务先匹配策略，再以 Policy Overlay 修改基础 Planner 的检索任务图。

## 5. 预计保护重点

独立保护构思围绕 F1—F4 的协同链条展开；BM25、向量检索、reranker、某一具体 LLM、固定阈值、固定 Top-k、知识图谱和基础模型在线微调均不作为必要特征。

航空电子领域在正文中通过以下技术环境落地：装备/模块对象识别、维修手册/原理资料/故障案例/测试规程/器件资料等多源知识、版本元数据、证据类型覆盖要求，以及对错误经验污染和版本冲突的控制。
