## 1. 最接近的现有技术 D1

### D1：CN119226439B《检索增强生成模型的控制方法、装置、设备及可读介质》

公开链接：<https://patents.google.com/patent/CN119226439B/zh>

D1 根据用户上下文和历史交互生成动态适应性关键词，提取文档特征，并根据用户对生成结果的反馈调整关键词生成规则、文档特征提取策略；其部分实施方式还利用强化学习调整生成策略。D1 已经明确覆盖“历史交互/用户反馈 → 调整 RAG 检索或生成策略”的基本思想，因此本案不能把“根据反馈优化 RAG”本身作为创新核心。

将 D1 作为最接近现有技术的原因：其技术目的和本案一样均涉及让 RAG 在连续使用过程中改变后续行为，且已具体涉及关键词规则、文档特征策略及强化学习调整，是当前检索结果中对“跨任务自优化 RAG”最直接的技术起点之一。

## 2. 组合风险较高的 D2

### D2：CN121329086A《一种基于多智能体与检索增强生成的智能管理调度系统及方法》

公开链接：<https://patents.google.com/patent/CN121329086A/zh>

D2 已公开任务智能体、协调智能体、知识智能体的多智能体分层结构，知识智能体中集成 RAG；任务执行结果反馈用于持续优化任务智能体决策模型与协调智能体预测模型，形成“感知—预测—求知—决策—执行—反馈—学习”闭环。

因此，本案同样不能仅以“Agent + RAG + 反馈闭环 + 持续学习”作为区别点。

### 非专利近邻：RSIAgent

论文：*RSIAgent: Autonomous Exploration for Recursive Self-improvement in New Environments*  
arXiv：<https://arxiv.org/abs/2609.15364>  
源码：<https://github.com/AetherLabsAI/RSIAgent>

RSIAgent 已公开 training-free recursive self-improvement：Actor 执行、Verifier 独立验证、Curriculum 选择后续探索，并把经过验证的行动—条件—结果经验沉淀进持久化 memory；源码还具有 memory distillation、whole-memory reconciliation、journal 和可恢复边界。

因此，本案不能把“经过验证的经验写入 memory 并供未来 Agent 复用”泛化描述为独有创新。真正需要保护的是该 RSI 原理在 RAG 知识获取流程中的专门化机制，即“检索轨迹 → 检索经验单元 → 检索编排策略 → Policy Overlay 改变未来检索任务图”，以及航空电子知识任务的证据约束和防污染机制。

## 4. D1 主比对与区别特征 Fk

| 编号 | 技术维度 | D1 CN119226439B | 本案怎么做 |
|---|---|---|---|
| F1 | 经验对象 | 主要依据用户反馈调整关键词生成规则、文档特征提取策略及生成策略 | 记录经过独立证据验证的完整检索执行轨迹，并提炼为 REU；REU 同时包含任务条件、检索动作、执行结果、策略效果诊断、验证状态和来源/知识库版本 |
| F2 | 跨任务策略形成方式 | D1 以反馈驱动模型/规则策略调整为主 | 对适用条件相近的正向与负向 REU 做对比式提炼，对多条经验聚合并进行全局冲突消解，生成带适用范围、可信度、支持经验、反例和版本信息的检索编排策略 |
| F3 | 对 Agent 行为的作用位置 | D1 未以检索任务图和工具编排智能体为核心 | 保留基础 Planner，以 Policy Overlay 作用于后续检索任务图，修改任务分解、查询扩展、知识源路由、检索工具序列、上下文扩展或停止条件中的至少一项 |
| F4 | 防污染与可逆演化 | D1 根据反馈达到条件后调整相关策略 | 设置 Outcome Gate 与 Policy Gate，区分候选经验、已验证经验和晋级策略；策略更新保留知识库版本、支持/反例和版本日志，并允许在后续冲突验证时缩小适用范围、降权、失效或回滚 |

### 特征一览

- **F1 已验证检索经验单元**：从完整检索执行轨迹中形成包含任务条件、检索动作、结果、诊断、验证和来源版本的 REU，而非仅存问答或用户评分。
- **F2 对比聚合与策略协调**：通过正负经验对比、多经验聚合和冲突消解形成带适用范围与可信度的检索编排策略。
- **F3 Policy Overlay 驱动未来 Agent 规划**：将匹配到的检索编排策略作为覆盖信息注入基础 Planner，直接改变未来任务的检索任务图或工具编排。
- **F4 双门控和版本化回滚**：未经可靠验证的轨迹不得直接进入策略层，策略在后续任务中继续被升权、降权、限定、失效或回滚。

## 6. 三段绑定：特征—效果—实际技术问题

| 特征 | 直接技术效果 | 实际解决的技术问题 |
|---|---|---|
| F1 | 把一次任务中可验证的检索行为转化为结构化、可追踪的可复用经验 | 相似任务重复从零规划，历史日志不能稳定复用，且无法区分事实结果与策略诊断 |
| F2 | 从多次正负经验中提炼稳定检索行为并处理冲突、过时和例外 | 单次经验易过拟合，长期记忆相互矛盾或随文档版本变化而失效 |
| F3 | 让经过验证的历史经验真正改变后续知识获取路径，而不是仅作为附加聊天上下文 | Agent 每次重新规划导致检索路径重复、知识源选择不稳定、复杂任务证据覆盖波动 |
| F4 | 阻止未验证经验污染长期策略，并使错误策略可追踪、可降级和可回滚 | 自优化过程中错误经验累积后会持续放大，难以恢复到稳定版本 |

## 7. 当前查新结论

1. **没有把“RSI-RAG Agent”名称本身当作新颖性依据。** 名称只能用于概念表达。
2. D1 已公开反馈驱动的 RAG 自学习；D2 已公开多智能体 + RAG + 反馈学习；D3 已公开正负反馈知识的后续利用；RSIAgent 已公开验证后经验沉淀与递归自改进。因此宽泛组合存在明显创造性风险。
3. 当前检索中**尚未发现一篇单独文献完整公开**“航空电子知识任务中的已验证检索轨迹 → REU → 正负检索动作对比/聚合与冲突消解 → 带适用范围和可信度的检索编排策略 → Policy Overlay 改写未来检索任务图 → 双门控及版本回滚”这一完整链条。
4. 因存在多文献组合风险，本案门禁定为**带疑点过**，继续成文；交底书应围绕 F1—F4 的相互作用写创造性，避免退化成“Agent + RAG + Memory”概念拼接。
